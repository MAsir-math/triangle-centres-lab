# TRIANGLE CENTRES LAB｜三角形的四心｜馬Sir教室

藍圖儀表板風格的中四「三角形四心」互動教學頁（外心、內心、形心／重心、垂心）。
**單一檔案 `index.html`**：CSS／JS／SVG 全內嵌，**不靠 CDN**，離線可用；**不收集學生資料**。

視覺風格參考技術藍圖儀表板（紙質底、分區面板、青色強調），課堂投影用克制動效，無「TOP SECRET」等科幻品牌字樣。

## 內容
- 中央 Canvas：拖動 A、B、C（滑鼠／觸控／方向鍵）；方格、吸附、坐標、歐拉線開關
- 預設：銳角、直角、鈍角、等腰、等邊
- 分頁：外心 O／內心 I／形心 G／垂心 H／全部顯示；概念卡、即時量度、狀態列、圖例
- 歐拉線（延伸）：OG : GH = 1 : 2；等邊提示四心重合
- 自我檢測 8 題（選擇 + 數值），即時回饋；無 cookie／localStorage／上傳
- 退化三角形警告（近共線）

## 本機預覽
雙擊 `index.html`，或：
```bash
python3 -m http.server 8000
```
開 <http://localhost:8000/>。

## 嵌入 Google Sites
1. **插入 → 嵌入 → 依網址**，貼上本頁的 **https** GitHub Pages 網址。
2. 嵌入框建議寬度拉滿、**高度約 1100–1400 px**。
3. 被 iframe 嵌入時右上角會出現「↗ 新分頁開啟」。

## 課堂用法
先用「銳角」逐個心配合口訣「外垂、內角、形中、垂高」；再切直角／鈍角預測外心、垂心位置；最後「全部顯示」＋可選歐拉線。投影建議全螢幕（F11）。

## 已知限制
- Sites 嵌入框高度固定，內容長時需框內捲動。
- 極鈍時外心／垂心／外接圓可能出畫面，狀態列會註「（畫面外）」。
- 直角判斷容許 ±0.5°；準確直角請用「直角」預設或開吸附。
- 作圖範圍固定（x：−4–16，y：−5–10）。
- 本 lab 版與舊版 `triangle-centres` 為**不同網址**，不會覆寫原課堂連結。
